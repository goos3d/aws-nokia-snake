# Nokia Snake

## Local Development & Testing
game, styled to look like the classic Nokia 3310 game.

Run locally by opening `index.html` in a web browser.

### Controls
- **Keyboard** - Arrow keys or WASD to navigate the snake.
- **Buttons** - Start, Pause, and Restart the game using the on-screen buttons.

### Testing
- Open the `index.html` file in a browser to test the game.
- Ensure the snake moves correctly according to input.
- Check that collisions with the snake's body, foods, and grid boundaries are handled properly.
- Verify the score and high-score tracking features.
- Manually test the pause and restart functionality to ensure they work as expected.
